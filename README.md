# test-app
Тестовый проект для изучения современных веб-технологий и мобильной разработки. Стек: Next.js (SSR, MobX, Axios, ECharts) для веб-дашборда, React Native (Expo) для мобильного приложения, Node.js (Express) для бэкенда с API. Реализован дашборд с отображением статистики и пользователей, данные фетчатся из бэкенда.
